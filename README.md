
## B&B Traders BD — E-commerce Website

A web-based E-commerce Management System developed using PHP, MySQL, HTML5, CSS3, and JavaScript.

The project is a full end-to-end online store built for B&B Traders BD, covering the complete customer purchase journey alongside a dedicated admin panel for managing products, orders, customers, and store settings.

The system includes the customer-facing storefront, customer account area, and admin panel — with frontend, backend, database integration, CRUD operations, validation, image upload, search, filtering, cart/checkout workflow, and order management functionality.

### Project Overview

The main objective of this project is to provide B&B Traders BD with a fully functional, independent e-commerce platform covering product browsing, ordering, and store administration.

### Implemented Areas

- Home Page
- Shop (Search, Filter, Sort, Pagination)
- Product Detail (Gallery, Variants, Reviews)
- Cart & Checkout
- Order Tracking
- Customer Account Dashboard
- Customer Orders & Order Detail
- Wishlist
- Profile & Password Management
- Admin Dashboard
- Admin Product Management (Add/Edit/Delete, Variants, Image Upload)
- Admin Category Management
- Admin Order Management
- Admin Customer Management
- Admin Coupon Management
- Admin Review Moderation
- Admin Store Settings

The project follows a modular PHP architecture and uses MySQL for persistent data storage, with a 16-table relational schema.

### System Design

The application was built around a typical retail e-commerce workflow, covering:

- Storefront layout and navigation
- Product listing and detail pages
- Shopping cart and checkout flow
- Order tracking for guests and registered customers
- Customer account management
- Admin-side inventory, order, and customer management
- Coupon and discount handling
- Review and rating system

The application was independently implemented in PHP with a custom-built database schema tailored to B&B Traders BD's requirements.
